## 🚀 Projects

### 1. [NutriVision — AI Food Analyzer](https://github.com/bhaveshyadav111/NutriVision)

An AI-powered food analysis application that predicts a dish from an uploaded image and uses the Gemini API to generate nutritional information.

- **Model:** InceptionResNetV2 with transfer learning and fine-tuning
- **Classification:** 80 food categories
- **Stack:** TensorFlow, Keras, Flask, Hugging Face Hub, Gemini API
- **Deployment:** Model hosted on Hugging Face Hub and loaded by the application
- **Focus:** Connecting computer vision inference with an external generative AI API

[![Hugging Face Model](https://img.shields.io/badge/Model-Hugging%20Face-FFD21E?style=flat-square&logo=huggingface&logoColor=black)](https://huggingface.co/Bhavesh540/NutriVision)

### 2. Dog vs. Cat Image Classification

Built image classification models using a custom CNN and transfer learning to classify dog and cat images.

- Trained with approximately 20,000 images.
- Implemented CNN architectures using TensorFlow/Keras.
- Used Xception with pretrained weights, followed by fine-tuning.
- **Reported result:** Approximately 99% validation accuracy after fine-tuning.
- Explored preprocessing, augmentation, regularization, and model evaluation.

### 3. [Loan Approval Prediction](https://www.kaggle.com/code/bhaveshyadav111/loan-approval-project)

A classification project focused on predicting loan approval and improving preprocessing consistency across different ML algorithms.

- Compared multiple classification algorithms.
- Fixed preprocessing issues involving one-hot encoding and feature scaling.
- Used a shared `ColumnTransformer` to apply model-appropriate preprocessing.
- **Best reported result — Decision Tree:**
  - Test accuracy: **93.5%**
  - Test precision: **87.7%**

### 4. Stroke Prediction

Developed and compared machine learning models for stroke prediction, with a focus on evaluation and classification performance.

- Compared Gradient Boosting, AdaBoost, and Logistic Regression with cross-validation.
- Investigated data leakage and class imbalance.
- **Reported validation accuracy:**
  - Gradient Boosting: **89.82%**
  - AdaBoost: **89.52%**
  - Logistic Regression with cross-validation: **85.69%**
- Explored deploying the model through Flask.

### 5. Heart Disease Prediction

Built a scikit-learn pipeline for heart disease classification, emphasizing reliable preprocessing and recall-oriented evaluation.

- Used `ColumnTransformer`, `StandardScaler`, and `LogisticRegressionCV`.
- Worked on preventing data leakage and addressing class imbalance.
- Prioritized recall as an important evaluation metric for a medical classification task.
- **Status:** FastAPI and Docker deployment in progress.

### 6. Car Sales Prediction with an ANN

Built an artificial neural network for a car sales prediction task.
